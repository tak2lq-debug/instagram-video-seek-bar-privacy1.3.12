Instagram Video Seek Bar 1.3.2

【インストール／更新】
1. ZIPを展開してください。
2. Microsoft Edge: edge://extensions （Chrome: chrome://extensions）を開く。
3. 開発者モードをオンにして「展開して読み込み」を選択。
4. ZIP内の instagram-seekbar-extension フォルダーを指定。
5. 同じ機能の旧バージョン（1.3.0 / 1.3.1）が別の拡張機能として残っている場合は必ず無効化または削除してください。
6. 既に開いているInstagramのタブは再読み込みしてください。

【1.3.2 の修正】
- [重要] CSSの display:flex!important によって非表示指定が効かず、スクロール済み動画のシークバーが表示され続ける問題を修正。
- シークバーを動画の表示領域に合わせて表示。画面外、スクロールコンテナの外、別モーダルの背面では非表示。
- InstagramがDOMから除去した動画のバーを削除、イベントリスナーも解除。
- Instagramが保持する重なった動画からシークバーが何重にも出ないよう表示を抑制。
- プレビュー動画と拡大画像を通常の動画・画像と誤認識して二重にボタンを付けない。
- 画像拡大ボタンを画像内右上の「白い＋付き虫眼鏡」に変更。
- スクリーンショットボタンを動画内左下（バーの少し上）の「白いカメラ」に変更。
- 入れ子のスクロール領域、ページ表示切り替えの更新に対応。

【既存機能】
シークバー（ホバーで太くなる）、シーク位置プレビュー、拡大画像表示、
動画PNGスクリーンショット、幅の狭いウィンドウ対応。
設定ポップアップから、太さ・色・透明度・つまみを変更できます。
設定はブラウザのストレージに保存します。

【注意】
InstagramのHTML構造や動画配信方式の変更により一部の機能が動かない場合があります。
ブラウザのCORS制限により、一部の動画はPNG保存・シーク位置プレビューできません。
